valor_IA - Robo WhatsApp do cliente

1. Extraia esta pasta na Area de Trabalho do computador que ficara com o WhatsApp aberto.
2. Execute INSTALAR_E_ABRIR_ROBO_VALORIA.bat.
3. Quando abrir http://localhost:3010, leia o QR Code com o WhatsApp do cliente.
4. Para iniciar junto com o Windows, execute INSTALAR_ROBO_INICIAR_COM_WINDOWS.bat.
5. Para remover da inicializacao, execute REMOVER_ROBO_DA_INICIALIZACAO.bat.
6. Se o WhatsApp pedir novo QR Code ou trocar de numero, feche o robo e execute RESETAR_QR_CODE_ROBO.bat.

Nao apague firebase-config.js nem robo-config.json. Eles vinculam este robo ao tenant correto no Prec_IA.
