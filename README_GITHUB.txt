SUBIR NO GITHUB PAGES

Envie somente o conteudo desta pasta para o repositorio do GitHub Pages.
Arquivos principais: index.html, fornecedor.html, config.html, firebase-config.js, styles.css, valorIA_app.js, fornecedor_app.js, config_app.js, pdf.min.js e pdf.worker.min.js.

Nao envie a pasta 02_PC_CLIENTE_ROBO para o GitHub. Nao envie server.js, package.json do robo, BATs, node_modules, .wwebjs_auth ou .wwebjs_cache.

Fluxo:
1. Abra config.html com usuario admin autorizado em adminEmails.
2. Cadastre o estabelecimento, e-mail autorizado, nicho e permissoes globais.
3. O cliente abre index.html e cria a propria senha.
4. Fornecedores respondem por fornecedor.html usando link publico sanitizado.
